this file serves as a cheatsheet for the features of Markdown.

1. Headings: Starting a line with a hash \# and a space makes a header. The more \#, the smaller the header.
   > \## This is a heading
   ## This is a heading
2. Line break: Add a \\ at the end of a line to break it.
   > Line 1\\Line 2\
  Line 1\
  Line 2
